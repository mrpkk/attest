# Contributing

Спасибо, что хочешь помочь. Правил мало, и все они проверяемые.

## Что нужно

- Python 3.10+
- **Живой прогон тестов** — критерий «готово» это вывод команды, а не обещание

## Как начать

```bash
git clone https://github.com/mrpkk/REPO.git
cd REPO
python3 -m pip install -e ".[dev]"
python3 -m pytest tests/ -q
```

Если тесты не зелёные до твоих правок — напиши, это важно.

## Правила

1. **Один коммит — одно изменение.** Понятное сообщение, что сделано.
2. **Тест на каждое поведение.** Новое поведение без теста не принимается.
3. **Никаких секретов в коде.** Ключи — только в окружении (`.env`), и он в
   `.gitignore`. Проверь перед коммитом:
   ```bash
   rg -n 'ghp_|sk-or-v1|sk-|hf_|0x[a-fA-F0-9]{40}' --glob '!tests/*'
   ```
4. **Не меняй публичный контракт без обсуждения.** Имена функций, формат
   ответа и коды ошибок — это то, на что ссылаются агенты.
5. **Не добавляй тяжёлые зависимости.** Ядро сознано без них; если
   зависимость действительно нужна — обоснуй в описании PR.

## Коммиты и PR

- Ветка от `main`, имя — что делает: `fix-price-rounding`
- В описании PR: **что изменилось, почему, как проверить**
- Если меняется поведение — обнови `README.md` в том же PR

## Чего не делать

- Не удалять тесты, чтобы «стало зелено»
- Не ослаблять проверки в `tests/` без причины в описании
- Не публиковать чужие данные в примерах и тестах
