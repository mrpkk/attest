# Changelog

Формат: [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/),
версии по [SemVer](https://semver.org/lang/ru/).

## [0.1.0] — 2026-10-06

Первый публичный релиз. Подпись версии — зелёный прогон тестов:
**138 passed**, сборка колеса `attest-0.1.0-py3-none-any.whl` успешна.

### Добавлено

- `core.py` — контракт артефакта: типы, `required`, `enum`, `pattern`, границы.
- `poison.py` — 20 сигнатур отравления + структурный канал
  `injection_in_data_field` (инъекция не в тексте, а в имени поля).
- `provenance.py` — HMAC-SHA256 над канонизированной записью: артефакт
  нельзя подменить после проверки.
- `schema.py` — верификация схемы с кодами `0/10/20` (пригоден для CI).
- `service.py` — HTTP: `/`, `/verify`, `/pricing`, `/health`.
- `cli.py` — stdin + `--schema`, `--verify`, коды возврата для пайплайнов.
- `mcp.py` — `initialize`, `tools/list`, `tools/call`: агент вызывает
  проверку как инструмент, а не как подпрограмму.
- `payment.py` — x402 v2: разбор `accepted`, заголовок `PAYMENT-SIGNATURE`.
- `server.json` + `gemini-extension.json` — манифесты подачи.
- `llms.txt`, `SKILL.md`, `llms-install.md` — машиночитаемая упаковка.
- `SECURITY.md`, `CONTRIBUTING.md` — канал отчёта об уязвимости и правила вклада.

### Исправлено

- **8 дыр, найденных аудитом реальных прогонов** — не ревью кода, а
  исполнением: каждая закрыта падающим при откате тестом.
- **Цена**: было $0,002 при себестоимости ≈$0,00146 (рельс 73% — рабочая
  маржа съедалась ошибкой округления). Стало $0,005, рельс ≈29%.
- **Бесплатный тариф** 20/сутки берётся из живого счётчика, а не с
  веб-страницы: страница могла разъехаться со счётчиком.

### Проверено вживую

- x402-фасилитатор принял подпись, адрес плательщика совпал, отказ получен
  только `insufficient_balance` — то есть протокол работает, денег просто нет.
- Конформанс JS/Python: **38/38**.

### Ограничения (честно)

- Живой платящий трафик не подключён: слой работает, но не заработан.
- Домен не куплен, в README плейсхолдер.
- Тарифы внешних LLM в прайсе = `PLACEHOLDER`, каталог печатает
  `PRICE TO VERIFY`.
- Проверка ловит известные классы инъекций, а не все возможные.
