# Установка attest для агента

Одна строка — сервер поднимается, ключи и регистрация не нужны.

```bash
claude mcp add --transport http attest https://REPLACE_WITH_DOMAIN/mcp
```

Проверка, что всё живо:

```bash
curl -s https://REPLACE_WITH_DOMAIN/health
# {"status":"ok","version":"0.1.0"}
```

Список инструментов:

```bash
curl -s -X POST https://REPLACE_WITH_DOMAIN/mcp \
  -H 'Content-Type: application/json' \
  -d '{"jsonrpc":"2.0","id":1,"method":"tools/list"}'
```

## Единственный инструмент

`verify_artifact` — проверить артефакт агента **до выплаты**.

| Аргумент | Обязательный | Что это |
|---|---|---|
| `artifact` | да | объект, массив или строка |
| `schema` | нет | JSON Schema, которой артефакт должен удовлетворять |
| `source` | нет | откуда артефакт, для записи в аттестации |

Возвращает вердикт `accept` / `review` / `reject`, доверие 0–100, конкретные
находки и подпись. Проверка по правилам, не LLM: одинаковый артефакт всегда
даёт одинаковый результат.

## Когда вызывать

Перед принятием работы от другого агента и перед любой выплатой. Особенно
если артефакт пришёл из внешнего источника: MCP-сервер в каталоге может
отдавать как обычные данные, так и инструкции для модели.

## Оплата

Бесплатно — 20 проверок в сутки на адрес, полный функционал. Сверх лимита —
оплата за вызов по протоколу x402 (0.005 USDC в сети Base), без подписки.
