## Заметки / рецепты

- **Листинг в x402 Bazaar не требует ни регистрации, ни модерации** — цена назначается
  продавцом, каталогизация происходит автоматически при обработке платежа с расширением
  `bazaar`. Первый платящий клиент одновременно публикует сервис. Я ошибочно считал, что
  для Bazaar нужен аккаунт: это не так, и канал замкнут сам на себя.
- **Требования сканеров каталогов, уже закрытые в коде:** `resources/list` и
  `prompts/list` возвращают пустые списки, а не «метод не найден»; у инструментов полные
  аннотации `title`/`readOnlyHint`/`destructiveHint`/`openWorldHint` — без них Anthropic
  не примет листинг; отказ проверки возвращается как результат инструмента с
  `isError: true`, а не протокольной ошибкой, потому что рецензент видит «Internal error».
- **Base Sepolia — путь без денег:** полный цикл (подпись → расчёт → каталогизация)
  проверяется тестовыми USDC из публичного крана. Единственный способ честно закрыть
  приём оплаты, не покупая ничего.
- **Проверять парсер платежа живым фасилитатором, а не тестом.** Три бага в v2
  (`scheme` внутри `accepted`, имя домена `USDC` против `USD Coin`, заголовок
  `PAYMENT-SIGNATURE`) нашлись только на живом ответе. Тесты на них не смотрели.
- **Три из четырёх живых дефектов не ловятся тестами:** обещание 20 при лимите 3,
  неразобранные подстановки в шаблоне, 413 без чтения тела, падение из-за опечатки в
  конфиге. Живой запуск — отдельный класс проверки.
- **Имя токена в домене различается между сетями.** Base mainnet — `USD Coin`,
  Base Sepolia — `USDC`. Одна константа на обе сети ломает подпись.
- **Собирать продакшн-страницу только из живого счётчика.** Обещание на странице,
  расходящееся с реальным лимитом, — это враньё клиенту, даже если код честен.
- **Сверять с `drift`, а не дублировать.** Разные моменты времени и разные вопросы:
  `attest` — задним числом, `drift` — заранее. Ложь внутри лимитов закрывает `attest`.
